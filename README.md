--Jogo da Forca

Jogo da forca desenvolvido em Python.

--Sobre o projeto
O objetivo é descobrir a palavra secreta antes que as seis tentativas acabem.

--Funcionalidades
- Escolha aleatória de palavras.
- Verificação de letras corretas e incorretas.
- Validação das letras digitadas.
- Impedimento de letras repetidas.
- Opção de jogar novamente.
- Avaliar o jogo

--Tecnologias utilizadas
- Python
- Biblioteca Random

--Conceitos praticados
- Funções
- Listas
- Estruturas condicionais
- Estruturas de repetição
- Validação de dados
